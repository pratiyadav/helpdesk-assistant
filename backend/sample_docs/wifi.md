# Wi-Fi

Employees connect to the network named ACME-Secure using their company username and password. Guests must use ACME-Guest, which is isolated from internal systems and requires a daily code from reception. Guest codes expire at midnight.

Personal devices must connect to ACME-Guest unless they are enrolled under the BYOD policy. If Wi-Fi drops repeatedly, forget the network, reconnect, and then raise a ticket that includes the access point label printed on the ceiling unit near you.
