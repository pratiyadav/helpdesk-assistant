# Software Requests

Pre-approved software can be installed from the Company Portal without a ticket. The pre-approved list includes Microsoft Teams, Zoom, Google Chrome, Visual Studio Code, 7-Zip and Adobe Acrobat Reader.

Any other software needs a Software Request ticket with a business justification. The security review takes 5 to 10 business days. Software with a personal license must not be installed on company laptops.

Admin rights are never granted permanently. Temporary admin access lasts 4 hours and is granted by the Service Desk after manager approval.
